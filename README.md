# K3b Distrobox

An Arch-based Distrobox container pre-configured for K3b

## Setup Instructions

Simply clone this repository and run the setup script:

```bash
git clone https://github.com/owen-debiasio/distrobox-k3b.git
cd distrobox-k3b
./setup.sh
```

## Launching K3b

```bash
distrobox enter k3b -- k3b
```
